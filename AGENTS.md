# AGENTS.md — agi

This repo holds the collected phexts and their nightly merge into
agi.phext.

- Canonical sources live elsewhere (see SOURCES.md). Edit a phext
  at its source, never the copy here.
- agi.phext is generated by build_agi_phext.py under
  MERGE-RULES.md — never hand-edit it.
- Merge-rule changes that alter precedence, the annex band, or
  what counts as a conflict are Will-level decisions.
- mastery.phext is refreshed by the Thirst for Knowledge quest's
  journal step. It is published alongside the collection and is
  not a merge input.
